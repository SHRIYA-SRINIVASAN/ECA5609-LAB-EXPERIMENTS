Experiment No. 1: Simulation of FDMA in MATLAB
Objective 1:To simulate an FDMA (Frequency Division Multiple Access) system by allocating individual frequency channels to multiple users.
Output Parameter:Channel Bandwidth (kHz).
Objective 2:To calculate the data rate achieved by each user based on the allocated channel bandwidth in the FDMA system.
Output Parameter:Data Rate (kbps).
Objective 3:To evaluate the communication quality of the FDMA system by calculating the Signal-to-Noise Ratio (SNR) for different users.
Output Parameter:Signal-to-Noise Ratio (SNR) (dB)
